Let the ESP download the update:

The ESP fetches the files from GitHub over https. It uses range requests, because GitHub would otherwise send 16 kB TLS records which do not fit in the memory of an ESP8266. This needs about 15 kB of free heap - if that fails, use the browser assisted update below.

Let this browser do the download:

Your phone or computer downloads the firmware from GitHub and pushes it to the ESP over your local network. No https on the ESP, so this works even when its memory is almost full. Works with the web files checkbox above as well.
